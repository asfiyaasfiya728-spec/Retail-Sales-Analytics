# 📊 Retail Sales Analytics

## 📌 Project Overview
A complete retail sales analytics project built using Excel, SQL, Python, and Power BI to analyze sales performance, customer behavior, and profitability.

## 🎯 Business Problem
Analyze retail sales data to identify top-performing products, profitable categories, regional trends, and actionable business insights.

## 🛠️ Tools & Technologies
- Excel
- SQL
- Python (Pandas, NumPy, Matplotlib)
- Power BI

## 📂 Repository Structure
- Dataset/
- Excel/
- SQL/
- Python/
- PowerBI/

## 📈 Project Workflow
1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. SQL Analysis
5. Python Analysis
6. Dashboard Development
7. Business Insights

## 📊 Key Insights
- Top-performing product categories
- Regional sales comparison
- Most profitable products
- Customer purchasing trends
- Sales performance dashboard

## 🚀 How to Run
1. Clone the repository.
2. Install dependencies:
   pip install -r requirements.txt
3. Open the Python, SQL, Excel, and Power BI files.
